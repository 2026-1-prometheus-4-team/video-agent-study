# Hooks Library — 후킹 멘트 카탈로그

`hook_suggest` tool 이 reference 로 사용. 첫 1-3 초 시청자 잡는 멘트.

## 5 가지 후킹 카테고리

### 1. 충격 통계 / 숫자

명시적 숫자 + 의외성. 한국에서 *가장 효과적*.

예시:
- "한 달 만에 1 천만 원 모은 진짜 방법"
- "이거 하나 바꿨더니 매출 3 배"
- "한국인 80% 가 모르는 영어 표현"
- "10 분 만에 끝나는 일주일치 식단 준비"
- "365 일 동안 매일 글 쓰고 깨달은 5 가지"

힘: 구체적 숫자 = 신뢰감 + 호기심.

### 2. 의외성 / 반전

상식 뒤집기. "이게 가능하다고?" 반응 유도.

예시:
- "사실 ___ 는 거짓말이었습니다"
- "이거 했더니 오히려 ___ 가 되었어요"
- "다들 이걸 ___ 라고 알고 있지만 진짜는..."
- "1 년 전엔 ___ 였는데 지금은 ___"
- "이 회사가 ___ 하는 이유는 우리가 모르는 ___ 때문"

힘: 인지 충돌 = 강한 주의 환기.

### 3. 질문형 (Curiosity Gap)

답을 모르고는 못 넘어가게.

예시:
- "왜 한국 카페는 항상 줄을 서있을까요?"
- "당신은 이 차이 알고 계셨나요?"
- "이거 진짜인지 직접 확인해 봤습니다"
- "만약 ___ 한다면 어떻게 될까요?"
- "이 사람들은 왜 ___ 하고 있을까요?"

힘: 답 = 영상 본문 → 완주율 보장.

### 4. 약속 (Promise)

명확한 가치 제공 약속. listicle / tutorial 에 적합.

예시:
- "이 영상 끝까지 보면 ___ 할 수 있어요"
- "3 분 안에 ___ 마스터하기"
- "이거 하나면 ___ 끝납니다"
- "오늘 알려드리는 ___ 가지 방법"
- "초보도 따라할 수 있는 ___"

힘: 실용 가치 명확 → 의도적 시청.

### 5. 5W1H (What/Why/When/Who/Where/How)

기자 스타일. 정보형 영상에 적합.

예시:
- "오늘 ___ 가 ___ 한 이유 (Why)"
- "이 사람이 ___ 한 정체는? (Who)"
- "___ 가 가장 잘 통하는 곳 5 곳 (Where)"
- "_정확히 어떻게 ___ 했는지 보여드릴게요 (How)"
- "___ 가 시작된 시기와 그 의미 (When)"

힘: 정보형 시청자에게 직접 어필.

## 포맷별 후킹 길이

| 포맷       | 권장 후킹 길이 | 특징                                                    |
|------------|----------------|---------------------------------------------------------|
| 쇼츠       | 0.5 - 2 초    | 매우 짧고 강함. 자막 + 시각 모먼트 동시.                |
| 릴스       | 0.5 - 2 초    | 쇼츠와 유사 + 음원 첫 비트 동기화                       |
| 유튜브     | 3 - 8 초      | 인트로 일부. 영상 핵심 미리보기 + 채널 정체성 포함.     |
| 일반       | 1 - 5 초      | 사용자 의도에 맞춤                                      |

## 후킹 + 본문 연결 패턴

후킹과 본문이 *반드시* 약속 일치해야. 클릭베이트 = 신뢰 손상.

| 후킹 패턴            | 본문 첫 5 초 약속                          |
|----------------------|--------------------------------------------|
| 충격 통계            | 그 통계가 *어떻게 나왔는지* 즉시 보여줌    |
| 의외성 / 반전        | 반전의 *근거* 를 보여주기 시작              |
| 질문형               | 답을 *조금씩* 풀어나가는 빌드업             |
| 약속                 | 약속한 가치 *제공 시작* 명확                |
| 5W1H                 | 해당 W/H 의 *첫 사실* 제시                  |

## 한국 시장 특화 팁

- *반말 톤* (친근감) vs *존댓말 톤* (전문성) — 채널 정체성에 맞추되 *쇼츠는 반말 우세*.
- *이모지 강조 자막* — 후킹 첫 1 초에 큰 이모지 자막 (😱, 🤯, 💀, 🔥) 인기.
- *지역 특수성* — "강남", "한강", "MZ", "Z 세대" 같은 한국 키워드 후킹 강함.
- *시즌 / 이슈 연결* — 최근 이슈에 연결된 후킹 = 알고리즘 부스트.

## 환각 금지

- 후킹에 *구체적 숫자* 박을 때 → 사용자가 *그 숫자 실현 가능한지 확인*.
- "한 달 만에 1 천만 원" 같은 클릭베이트 → 본문이 그 정도 가치 아닌 경우 *경고 후 톤다운 제안*.
- 인용 시 출처 명시 ("___ 통계청 / OOO 채널 / OOO 기사").
