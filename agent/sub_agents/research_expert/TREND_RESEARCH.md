# Trend Research — 트렌드 분석 방법

## 트렌드 시계

| 카테고리           | 변화 주기    | 데이터 소스                          |
|--------------------|--------------|--------------------------------------|
| 쇼츠 / 릴스       | **주 단위**  | YouTube trending + 인스타 릴스 검색 |
| 유튜브 (장편)     | 월 단위      | YouTube trending + 채널 분석          |
| 음악 / BGM        | 월 ~ 분기    | 인기 음원 차트 + 영상 BGM 분석        |
| 자막 / 폰트       | 분기         | 베스트 영상 자막 스타일 추출          |
| 색감 / 색보정     | 분기 ~ 반기  | 베스트 영상 dominant color 분석       |

## 한국 시장 특수성

### 후킹 패턴 (한국)

1. **리액션 / 의외성** — "헐 진짜?" / "이게 가능해?" 톤. 5W1H 형식 적음.
2. **공감 + 자조** — "나만 이래?" / "MZ 직장인이면 이거 모름 X". 친근감.
3. **숫자 + 충격** — "한 달 만에 100 만원 모은 비결" / "1 분만에 ...". 구체 숫자 강력.
4. **질문형 후킹** — "당신도 이러시나요?" / "왜 [트렌드/현상] 일까?". 호기심 유도.
5. **밈 활용** — 시즌별 밈 / 짤 / 유행어 인용. *유통기한 짧음 주의*.

### 자막 스타일 (한국)

- 한국어 폰트: Pretendard, Noto Sans KR, TT Norms (영문 혼용), G마켓 산스
- 강조 색: 노랑 (#FFE600), 형광 핑크 (#FF2E63), 파랑 (#3D5AFE)
- 이모지 자막 증가 — 특히 쇼츠 / 릴스 (감정 강조)
- 한 줄 12 자 ~ 15 자, 화면 중앙 정렬 (쇼츠)

### 음악 / BGM (한국)

- 쇼츠 / 릴스 = *유행 음원* (틱톡 음원 + 차트 인기곡). 저작권 회피용 *비슷한 mood* BGM 추천 권장.
- 유튜브 = 자체 채널 BGM (저작권 무료). Epidemic Sound, Artlist 종류.
- 카페 / 일상 영상: Lo-fi, Acoustic
- 챌린지 / 텐션: K-pop dance, EDM
- 감성 / 여행: Indie pop, Cinematic instrumental

## 카테고리별 best practice

### 쇼츠 (60 초 이하)

- *첫 1 초 후킹* — 자막 + 강한 시각 모먼트 동시.
- 컷 평균 1-3 초. 빠른 호흡.
- 자막 = *큰 폰트 화면 중앙*.
- BGM = 일정한 텐션 (드롭은 후반).
- CTA = 마지막 2 초 ("팔로우" / "좋아요" / "댓글로 알려줘").

### 유튜브 (5 ~ 15 분 일반)

- 인트로 5-10 초 — 영상 핵심 미리보기 + 채널 정체성.
- 본문 컷 평균 5-15 초 호흡.
- 자막 = 보조 (말 빠를 때만 / 키워드만).
- 아웃트로 = 다음 영상 추천 + 채널 구독 + 좋아요.

### 릴스 (90 초 이하)

- 쇼츠와 유사 + *음원 트렌드 강함*.
- 인스타 알고리즘은 *완주율* 중요 → 끝까지 보게 만드는 마이크로 후킹 (중간에 한 번 더).

## 트렌드 분석 워크플로우 (research_expert 가 따름)

1. **macro**: `youtube_trend(category, region)` 으로 카테고리 트렌드 영상 10 개
2. **micro**: 그 중 평균 조회수 상위 3 개의 *공통 패턴* 추출 (`channel_analysis` 또는 메타로)
3. **insights**: 공통점 → 인사이트 3-5 개 (5 줄 이내)

## 출처 / 데이터 소스

- YouTube Data API v3 (한국 region code: "KR")
- 한국 인기 채널: 뉴진스, 침착맨, 슈카월드, 빠니보틀, 곽튜브 등 (장르별 다름)
- 음원 차트: 멜론 차트, 빌보드 K-pop, 틱톡 트렌딩
- 폰트 트렌드: Pretendard / SAN Family / G마켓 (한국 변형)
- *우리는 데이터 *생성* 안 한다*. 항상 search → cite.
