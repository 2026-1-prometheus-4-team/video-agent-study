# Concept Patterns — 영상 스토리텔링 카탈로그

`concept_brainstorm` / `storyboard_from_concept` tool 이 reference 로 사용.
사용자에게 컨셉을 제안할 때 *반드시 이 12 가지 중 하나에 매핑* 해서 명확히 설명.

## 12 가지 스토리텔링 패턴

### 1. Problem-Solution
**구조**: 문제 제시 → 솔루션 제시 → 결과/검증
**적합**: 제품 / 서비스 / 노하우 / 팁
**예**: "맨날 늦잠? 이 방법으로 7시 기상 성공한 비결"
**힘**: 공감 + 해결 욕구 자극
**길이**: 쇼츠 30-60s / 유튜브 3-7 분

### 2. Before-After
**구조**: 변화 전 (충격) → 과정 → 변화 후 (성과)
**적합**: 변신 / 다이어트 / 정리 / 학습
**예**: "원룸 비포 vs 애프터 — 하루 만에 인테리어 BIG CHANGE"
**힘**: 시각적 변화 = 즉각적 임팩트
**길이**: 쇼츠에 최적

### 3. Listicle (N가지)
**구조**: "X 가지 ___" 약속 → 순서대로 보여줌 → 종합 정리
**적합**: 팁 / 도구 / 음식 / 장소
**예**: "한국 사람만 모르는 5 가지 한국어 표현"
**힘**: 명확한 양적 약속 → 완주율 높음
**길이**: N 에 비례 (5 = 60-90s, 10 = 4-7 분)

### 4. Tutorial
**구조**: 결과 미리보기 → 준비물 → 단계별 → 완성
**적합**: 요리 / DIY / 코딩 / 메이크업
**예**: "초보도 1 시간에 만드는 인스타 감성 라떼아트"
**힘**: 실용 가치 명확
**길이**: 유튜브 5-15 분 권장

### 5. Transformation
**구조**: 처음 상태 → 시도/실패 반복 → 마침내 변신
**적합**: 성장 / 학습 / 챌린지 후일담
**예**: "프로그래밍 0 일차 → 100 일차 변화 기록"
**힘**: 서사 + 감정 이입
**길이**: 유튜브 5-12 분

### 6. Day-in-Life
**구조**: 시간 순서대로 하루 활동 보여줌
**적합**: 직업 / 라이프스타일 / 여행
**예**: "신입 개발자의 평일 하루 — 출근부터 퇴근까지"
**힘**: 호기심 / 친근감
**길이**: 유튜브 4-10 분

### 7. Challenge
**구조**: 도전 선언 → 시도 → 결과 (성공 / 실패)
**적합**: 챌린지 / 게임 / 음식 / 체험
**예**: "24 시간 한국 편의점 음식만 먹기 챌린지"
**힘**: 결과 궁금증 → 완주율
**길이**: 쇼츠 30-60s / 유튜브 5-15 분

### 8. Journey
**구조**: 여정 시작 → 중간 발견 / 위기 → 도착 / 종료
**적합**: 여행 / 등산 / 모험 / 학습
**예**: "혼자 배낭 메고 제주 한 바퀴 — 5 박 6 일"
**힘**: 동행 감각 / 풍경
**길이**: 유튜브 8-20 분

### 9. Mystery
**구조**: 의문 / 사건 제시 → 단서 추적 → 진실 공개
**적합**: 도시 전설 / 미스터리 / 분석
**예**: "이 가게가 항상 줄 서는 진짜 이유는?"
**힘**: 호기심 maximizer
**길이**: 유튜브 6-12 분

### 10. Fail-Success
**구조**: 실패 / 실수 보여줌 (자조) → 교훈 → 성공 방법
**적합**: 학습 기록 / 후회 / 노하우
**예**: "주식 -3000 만원 잃고 깨달은 5 가지"
**힘**: 자조 = 신뢰 / 진정성
**길이**: 유튜브 5-12 분

### 11. Comparison
**구조**: 옵션 A / 옵션 B 양쪽 보여줌 → 비교 → 결론
**적합**: 제품 리뷰 / 장소 / 방법론
**예**: "스타벅스 라떼 vs 동네 카페 라떼 — 블라인드 테스트"
**힘**: 명확한 결정 지원 가치
**길이**: 쇼츠 60s / 유튜브 5-10 분

### 12. Demonstration
**구조**: 도구 / 기술 소개 → 시연 → 결과 보여줌
**적합**: 제품 / 도구 / 기법 시연
**예**: "ChatGPT 로 1 시간 만에 PPT 만들기 — 실시간 시연"
**힘**: 시각적 입증
**길이**: 유튜브 3-10 분

## 쇼츠 / 유튜브 별 추천 패턴

| 포맷       | 추천 패턴 (상위 5)                                              |
|------------|----------------------------------------------------------------|
| 쇼츠       | Before-After, Listicle, Challenge, Comparison, Problem-Solution |
| 유튜브     | Tutorial, Transformation, Day-in-Life, Journey, Mystery        |
| 릴스       | Before-After, Challenge, Listicle, Demonstration, Fail-Success |
| 일반       | (사용자 의도에 맞춤)                                            |

## 컨셉 생성 시 따라야 할 형식

`concept_brainstorm` 의 출력은 다음을 *반드시* 포함:

```json
{
  "title": "구체적이고 후킹 있는 제목 (10-20 자)",
  "story_pattern": "위 12 가지 중 정확한 이름",
  "story_arc": "Hook -> [패턴별 중간 단계] -> CTA",
  "target_format": "shorts | youtube | reels | general",
  "estimated_duration_sec": 60,
  "audience": "사용자가 말한 청중 또는 추정",
  "differentiation": "이 컨셉의 차별점 (1 줄, 왜 시청자가 이걸 봐야 하나)",
  "risk": "잠재 리스크 / 저작권 / 민감 주제 표시"
}
```
